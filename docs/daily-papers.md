# 今日论文推荐

在论文库顶部点击「今日推荐」。首次使用填写或调整研究兴趣、英文检索词（每行一条）和篇数，点击「生成今日推荐」。默认画像覆盖大模型 RL、低比特训练/采样 mismatch 与 RL 加速。偏好保存在本机，AI 使用 Reader 设置中已通过检测的当前连接；连接失败时遵循已有备用 API 设置。

本功能先检索 arXiv 元数据；源不可用或没有候选时尝试 Semantic Scholar。经典论文和预印本均可出现，今天生成不代表论文今天发表。结果来自检索到的标题、作者、日期、摘要和链接；AI 仅选择候选并提供评分、理由和局限，不负责生成引用。评分是摘要级判断，按相关性 40%、启发性 25%、证据 20%、前沿性 15% 计算，不代表全文或代码已经核验。摘要缺失时应视为证据有限。

默认推荐 3～5 篇。候选不足时按实际数量显示并提示。按 DOI、arXiv 编号（去除版本后去重）和规范化标题识别重复，保留来源中的 arXiv 版本链接。书库中标记「已读」的论文不参与本轮筛选；已入库和最近历史中曾推荐的论文会显示标记。历史记录仍保留当时的推荐内容。

点击「导入论文库」复用现有论文下载流程；导入后可打开、翻译和问答。无法取得 PDF 时显示下载错误，可用来源链接手动访问。导入不会自动标记已读。

## 存储与生命周期

点击时才检索，不创建定时任务。一次推荐只执行一轮 AI 筛选，不保留跨日期的长会话。请求关闭/取消时中止后台工作；不完整或不合规的推荐不写入历史。此前保存的结果不会因本轮失败而删除。

偏好和最近 **30 次** 推荐保存在 Reader 书库的 SQLite settings 中，超过上限移除最旧推荐；网页只加载这 30 次。关闭模型后台释放其进程内存不等于擦除模型工具自己记录的日志。论文原文件和译文不受推荐历史上限影响。

## 验证

- Go：`go test ./internal/scholar` 与 `go test ./internal/reader -run TestPaperRecommendation`。
- UI：`pnpm exec vitest run apps/web/src/papers/daily-papers.test.tsx`。
- 可选真实链路：设置 `READER_TEST_PAPER_RECOMMENDATION_LIVE=1`，运行 `TestPaperRecommendationLive`。使用隔离临时书库，真实联网检索并调用已配置的 ZCode GLM-5.3-Flash/low，会消耗额度；不修改正在使用的 Reader 配置。
- 手动验收：保存偏好并重新打开、生成/取消、检查历史仍在、标记论文已读后重新推荐、导入并打开论文。界面检查由用户手动完成，不使用浏览器自动化。
