# ZCode 翻译会话复用

用户已确认：按翻译工作线程复用后台及会话，失败或取消时丢弃，结束时清理。

设计：沿用 Codex 的 worker 所有权，在现有 ZCode worktree 内实现。聊天与图片请求保持单次调用；翻译每个 worker 持有独立的后台、隔离目录与会话。单批超时不能成为后台的永久生命周期，取消必须向后台发送 stop 并有强制关闭兜底。每轮重置输出状态，保留事件序号以拒绝旧事件。模型切换重建。历史保留由 ZCode 原生上下文管理处理，不改变批次、模型或思考配置。

实施步骤：
- 先增加连续调用、错误重建、取消、清理及事件隔离测试，确认失败。
- 提取 ZCode 单轮发送流程，增加可复用会话及翻译适配器。
- 将适配器加入 translationSessions 的 worker 退出清理。
- 运行 Go 针对性测试及项目检查；记录真实结果，检查并提交独立变更。

验收：同一 worker 的成功批次只启动一次；其他 worker 独立；失败后下一次调用重新启动；退出删除隔离目录；成功输出必须收到 turn.completed。此次不发布安装包。

验证记录：
- 针对性 Go 测试通过，覆盖连续轮次、事件重放、独立 worker、失败/模型切换重建、保存失败、强制取消、目录清理及既有 JSONL 边界。
- 真实 ZCode 0.16.9：两次短翻译使用同一进程 PID 51872、同一会话对象；第一轮约 6.76 秒，第二轮约 4.04 秒。已验证第一轮 context 释放不影响下一轮；此结果不是整篇论文性能基准。
- `pnpm typecheck`、`pnpm build` 通过。
- `pnpm test` 未通过：已有 `TestRedactionAndFullExport`、`TestAgentStreamingBeforeCompletion` 失败，Go 测试 90 秒超时，后续 Vitest 未执行。没有将全套检查标为通过。
